# 政策数据校验与可视化口径

政策列表、统计和图谱读取同一项目材料，但投影可能使用不同字段口径。可视化前应明确数据范围、时间字段、地区字段和状态过滤，避免把不同查询结果当成同一事实。

## 基本校验

1. 文档属于当前项目且未被归档。
2. `doc_type` 与目标视图一致。
3. 地区可从 `Document.state` 或 `extracted_data.policy.state` 读取时使用同一回退规则。
4. 时间趋势必须说明采用 `publish_date`、`effective_date` 还是 `created_at` 兜底。
5. 空日期记录是否计入总量必须与图表标签一致。
6. 图谱节点和边保留原始文档来源，不用聚合图替代原文。

## 一致性

列表、统计和导出应复用同一项目过滤及字段回退规则。若某个视图因性能原因预先聚合，应保存聚合口径和版本，并允许从原材料重新计算。

时间趋势的总和可能小于文档总数，因为缺少可比较日期的记录不进入趋势。界面必须显示该差异，而不是把缺失日期默认为当前时间。

## 实时性

材料写入、索引完成和可视化刷新是不同状态：

- 材料已保存不表示索引已更新；
- 索引已更新不表示前端缓存已刷新；
- 图页可见不表示服务端关系已持久化。

界面应显示最后成功的数据读取时间或索引版本。实时性无法确认时显示未知或不完整，不用旧快照冒充当前结果。

## 性能

大范围统计优先使用数据库聚合或已批准索引投影；Python 层内存聚合只适合有界结果。任何预计算都必须可从材料重建，并保留实际查询范围。
