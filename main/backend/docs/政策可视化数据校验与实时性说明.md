# 政策数据校验与可视化口径

政策列表、统计和图谱读取同一项目材料，但投影可能使用不同字段口径。可视化前应明确数据范围、时间字段、地区字段和状态过滤，避免把不同查询结果当成同一事实。

## 基本校验

1. 查询绑定选中的项目。政策列表和统计筛选 `Material.material_type` 为 `policy` 或 `policy_regulation`，并要求有 `extracted_data.policy`。
2. 地区过滤、列表显示和统计分布目前并非同一规则：列表展示优先用政策提取字段；统计地区分布优先用 `Material.state`。核对差异时查看[政策路由](../app/api/policies.py)和[投影定义](../app/services/document_views/policy_view.py)。
3. 日期过滤及统计趋势依次取 `effective_time`、`source_time`、`policy.effective_date`、`publish_date`、`created_at`（取日期）。精确定义见[查询规则](../app/services/document_queries/policy_filters.py)。
4. 图谱节点和边应保留原始材料来源，不能用聚合图替代原文。

## 一致性

列表、统计和导出应复用同一项目过滤及字段回退规则。若某个视图因性能原因预先聚合，应保存聚合口径和版本，并允许从原材料重新计算。

比较趋势与总数前先核对实际时间口径、过滤条件及空日期处理，不要把缺失的发布日期替换成当前时间。

## 实时性

材料写入、索引完成和可视化刷新是不同状态：

- 材料已保存不表示索引已更新；
- 索引已更新不表示前端缓存已刷新；
- 图页可见不表示服务端关系已持久化。

界面应显示最后成功的数据读取时间或索引版本。实时性无法确认时显示未知或不完整，不用旧快照冒充当前结果。

## 性能

大范围统计优先使用数据库聚合或已批准索引投影；Python 层内存聚合只适合有界结果。任何预计算都必须可从材料重建，并保留实际查询范围。
