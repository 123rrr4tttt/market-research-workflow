# AI Governance — Minimal Baseline (F Line)

> Owner: SA3-R3 (F)  
> Date: 2026-03-04

## 1) 目标
对齐参考包 F 线（数据治理与 AI 工程）Must 最小集：
- 数据/特征/模型/评估版本化与可追溯
- 上线门禁（离线评估 + 在线监控 + 回滚策略）
- 高风险场景审计日志与人工复核

## 2) 最小治理骨架（本次固化）
### 2.1 版本化追溯四件套
每次模型/提示词/策略变更，至少保留：
1. 数据快照标识（日期、来源、范围）
2. 特征/输入口径版本（schema/hash）
3. 模型/提示词版本（tag/hash）
4. 评估报告版本（离线指标 + 样本）

### 2.2 上线门禁
上线前必须满足：
- 离线评估：定义基线指标（如准确率、召回率、F1 或业务指标）
- 在线监控：至少有失败率/异常率/延迟/漂移监控项
- 回滚策略：可在单次发布窗口内切回上一稳定版本

### 2.3 高风险场景控制
高风险输出需：
- 审计日志（输入摘要、输出摘要、版本号、时间）
- 人工复核（抽检或全量，按风险分级）

## 3) 参考标准映射
- NIST AI RMF：风险识别-治理-监测闭环
- MLflow/LakeFS：版本化与可追溯思路
- OECD AI Principles：可问责与可审计

## 4) 假设项
- 假设当前仓库仍在“RAG + 报告闭环”完善阶段，先固化制度基线，再逐步自动化。
- 假设在线监控可复用现有后端监控链路（日志/指标）。
