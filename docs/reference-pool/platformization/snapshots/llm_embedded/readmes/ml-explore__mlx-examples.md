MLX Examples
============

[](http://github.com/ml-explore/mlx-examples#mlx-examples)

This repo contains a variety of standalone examples using the [MLX framework](https://github.com/ml-explore/mlx).

The [MNIST](http://github.com/ml-explore/mlx-examples/blob/main/mnist) example is a good starting point to learn how to use MLX. Some more useful examples are listed below. Check-out [MLX LM](https://github.com/ml-explore/mlx-lm) for a more fully featured Python package for LLMs with MLX.

### Text Models

[](http://github.com/ml-explore/mlx-examples#text-models)

*   [Transformer language model](http://github.com/ml-explore/mlx-examples/blob/main/transformer_lm) training.
*   Minimal examples of large scale text generation with [LLaMA](http://github.com/ml-explore/mlx-examples/blob/main/llms/llama), [Mistral](http://github.com/ml-explore/mlx-examples/blob/main/llms/mistral), and more in the [LLMs](http://github.com/ml-explore/mlx-examples/blob/main/llms) directory.
*   A mixture-of-experts (MoE) language model with [Mixtral 8x7B](http://github.com/ml-explore/mlx-examples/blob/main/llms/mixtral).
*   Parameter efficient fine-tuning with [LoRA or QLoRA](http://github.com/ml-explore/mlx-examples/blob/main/lora).
*   Text-to-text multi-task Transformers with [T5](http://github.com/ml-explore/mlx-examples/blob/main/t5).
*   Bidirectional language understanding with [BERT](http://github.com/ml-explore/mlx-examples/blob/main/bert).

### Image Models

[](http://github.com/ml-explore/mlx-examples#image-models)

*   Generating images 
    *   [FLUX](http://github.com/ml-explore/mlx-examples/blob/main/flux)
    *   [Stable Diffusion or SDXL](http://github.com/ml-explore/mlx-examples/blob/main/stable_diffusion)

*   Image classification using [ResNets on CIFAR-10](http://github.com/ml-explore/mlx-examples/blob/main/cifar).
*   Convolutional variational autoencoder [(CVAE) on MNIST](http://github.com/ml-explore/mlx-examples/blob/main/cvae).

### Audio Models

[](http://github.com/ml-explore/mlx-examples#audio-models)

*   Speech recognition with [OpenAI's Whisper](http://github.com/ml-explore/mlx-examples/blob/main/whisper).
*   Audio compression and generation with [Meta's EnCodec](http://github.com/ml-explore/mlx-examples/blob/main/encodec).
*   Music generation with [Meta's MusicGen](http://github.com/ml-explore/mlx-examples/blob/main/musicgen).

### Multimodal models

[](http://github.com/ml-explore/mlx-examples#multimodal-models)

*   Joint text and image embeddings with [CLIP](http://github.com/ml-explore/mlx-examples/blob/main/clip).
*   Text generation from image and text inputs with [LLaVA](http://github.com/ml-explore/mlx-examples/blob/main/llava).
*   Image segmentation with [Segment Anything (SAM)](http://github.com/ml-explore/mlx-examples/blob/main/segment_anything).

### Other Models

[](http://github.com/ml-explore/mlx-examples#other-models)

*   Semi-supervised learning on graph-structured data with [GCN](http://github.com/ml-explore/mlx-examples/blob/main/gcn).
*   Real NVP [normalizing flow](http://github.com/ml-explore/mlx-examples/blob/main/normalizing_flow) for density estimation and sampling.

### Hugging Face

[](http://github.com/ml-explore/mlx-examples#hugging-face)

You can directly use or download converted checkpoints from the [MLX Community](https://huggingface.co/mlx-community) organization on Hugging Face. We encourage you to join the community and [contribute new models](https://github.com/ml-explore/mlx-examples/issues/155).
