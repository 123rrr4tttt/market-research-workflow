# 文档导航

日常阅读只需下面四个入口。专题文档在所属入口中链接，已完成方案与旧执行记录从历史资料查找。

| 目的 | 唯一入口 | 内容 |
| --- | --- | --- |
| 使用 | [使用说明](usage.md) | 日常操作、启停、认证和运行模式 |
| 架构 | [架构说明](architecture/README.md) | 模块关系、事实归属和专题设计 |
| 开发 | [开发指南](development/README.md) | 代码位置、贡献接入和验证命令 |
| 历史 | [历史资料](history/README.md) | 已完成方案、旧版本、归档与冻结证据 |

## 维护方式

- 使用步骤只在使用说明或对应服务 README 维护，其他入口链接过去。
- 稳定接口与架构在所属专题维护；能力清单从原生声明和实际源码查询。
- 开发方案实施完成后退出当前导航，结果与原始证据保留在历史入口。
- 历史记录中的“当前”“待办”和编号只描述当时状态；重新开发以当前源码和新任务为准。

目录名和历史路径用于定位资料，不要求使用者理解旧开发编号。
