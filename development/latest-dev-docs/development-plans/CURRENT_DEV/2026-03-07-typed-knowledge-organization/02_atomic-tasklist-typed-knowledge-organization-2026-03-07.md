# Atomic Task List: Typed Knowledge Organization (2026-03-07)

## 定位

本任务清单用于把类型节点、分册、专题聚类、双语化等要求整理成后续可继续细化的主题文档。

## 全局规则

- 先梳理现有数据组织基线，再提新模型。
- 先定义概念边界，再写自动化流程。
- 自动归类必须保留人工修正位置。

## Task A1: Confirm Existing Organization Layer

- 目标: 核对现有实体、标签、分类、图谱结构中已存在的组织能力。
- 输出:
  - one baseline map
  - one gap list
- 验收:
  - 说明“已有什么”和“缺什么”

## Task A2: Define Type Node Boundary

- 目标: 明确类型节点与普通信息节点、专题节点、标签体系的关系。
- 验收:
  - 至少一个关系样例
  - 边界不与其他概念混淆

## Task A3: Split Manual and Automatic Classification

- 目标: 明确自动归类、人工修正、双语化、分册之间的先后关系。
- 验收:
  - 至少一条自动归类流程
  - 至少一个人工校正点

## Task A4: Define Minimal Validation

- 目标: 预留后续实现的最小验证方式。
- 验收:
  - 至少一个类型节点样例
  - 至少一个分册或专题聚类验证点
