# Atomic Task List: Ingest Digestion and Long-Cycle Automation (2026-03-07)

## 定位

本任务清单用于把长文本消化、PDF 处理、二次产物消费和长周期采集任务整理成后续可继续细化的主题文档。

## 全局规则

- 先明确输入类型，再写统一流程。
- 时间密度能力必须作为已有基础复用，而不是另起一套时间语义。
- 下游知识组织去向要在文档里明确。

## Task A1: Confirm Input Classes

- 目标: 区分长文本、PDF、LLM 报告、用户写作文本等输入类别。
- 输出:
  - one input taxonomy
  - one processing difference list
- 验收:
  - 不同输入类型有清晰分层

## Task A2: Freeze Minimum Digestion Flow

- 目标: 明确“输入 -> 切分 -> 摘要/提取 -> 结构化结果”的最小链路。
- 验收:
  - 至少一条一般信息消化流程

## Task A3: Clarify Long-Cycle Task Boundary

- 目标: 明确长周期采集任务与时间密度能力的关系。
- 验收:
  - 至少一个时间相关设计点
  - 至少一个任务状态或调度点

## Task A4: Define Minimal Validation

- 目标: 预留后续实现的最小验证步骤。
- 验收:
  - 至少一个长文本/PDF 验证点
  - 至少一个长周期任务验证点
