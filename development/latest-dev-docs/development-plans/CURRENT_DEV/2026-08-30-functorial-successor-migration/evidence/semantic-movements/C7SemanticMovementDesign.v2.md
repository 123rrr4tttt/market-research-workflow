# C7 Semantic Movement Design v2

Status: `MAINLINE_DESIGNED · IMPLEMENTATION_EVIDENCE_PENDING · PROMOTION_BLOCKED`

Normative inputs: repository semantic-movement completeness standard and frozen amendments 20/21. This design supersedes v1. It fixes the semantic rows and dispositions that a deterministic worker may serialize; it does not authorize implementation, promotion, canonical write, live provider, delivery, cutover, authority transfer or candidate creation.

## Topology

```text
RawSnapshot
  -> NormalizedIngestEnvelope
  -> DigestionDecision
  -> exactly_one_of {Extract, Chunk, Summarize, PassThrough}
  -> StructuredMaterialCandidate
  -> C7.2 Verify
  -> C7.2 Admit
  -> independent SearchProjection and GraphProjection
```

The four alternatives have no edges between them, are not serial and make no commutativity claim. C7.4 is a failure/reverse-return/reconciliation view, not an unconditional successful-chain suffix. Legacy `CHUNK_FIRST + extract_required` and `SUMMARIZE_FIRST + extract_required` conflict with frozen `one_of`; they remain blockers until branch-internal semantics are separately fixed by mainline authority.

## Gate result fixed by design

Exact blocker IDs are `001,002,003,010,011,020,021,030,031,040,041,050,051,070,074`; `UNASSIGNED_BLOCKER == 15`. These block C7 pilot/family, dependent Slice A and P4/candidate claims only. They do not revoke or re-prove P0-P3 local-only records.

Declared losses are limited to C7-MOV-060 (`full_text`, `raw_payload`) and C7-MOV-061 (`text`, `raw_payload`). Global zero loss is false. Unaccepted losses in raw snapshot identity, normalized envelope fields, decision/branch provenance, structured candidate and verification/admission remain blockers.

Required legacy traces: STRUCTURED_JSON, long-report, derived-report, pass-through, return-for-cleanup. Missing target traces stay blocked. Long-report and derived-report dual-flag conflicts must not be silently normalized.

Double review must bind the same immutable inventory/matrix digests. Declared-scope review checks 20 unique rows, 13 fields, six dispositions, locator separation, topology and exact blocker calculation. Predecessor completeness review checks four modes, failure/reverse-return, loss account, contract-only movements and dependency scopes. With fifteen blockers the dependent-scope verdict must be BLOCK, never PASS.
