# C7 Semantic Movement Design v3

Status: `MAINLINE_REDISPOSITION_CANDIDATE · TARGET_IMPLEMENTATION_REVIEWS_PASS · DUAL_GATE_PENDING · NO_PROMOTION`

Normative inputs remain frozen amendments `20/21` and the repository semantic
movement completeness standard. This design supersedes v2 only as a candidate
movement disposition. It authorizes no production canonical write, live
provider, external delivery, cutover, authority transfer, candidate or P4
promotion.

## Topology

```text
RawSnapshot
  -> NormalizedIngestEnvelope
  -> DigestionDecision
  -> exactly_one_of {Extract, Chunk, Summarize, PassThrough}
  -> StructuredMaterialCandidate
  -> C7.2 Verify
  -> C7.2 disposable Admit/Readback
  -> independent SearchProjection and GraphProjection
```

The four alternatives are not serial and make no commutativity claim. Legacy
`CHUNK_FIRST + extract_required` and `SUMMARIZE_FIRST + extract_required` are
re-expressed as deterministic branch-internal structural formation. The local
provider-zero realization explicitly declares loss of legacy provider/model
enrichment; it does not claim provider parity. C7.4 remains a failure,
reverse-return and reconciliation view rather than a successful-chain suffix.
